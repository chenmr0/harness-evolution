# Agent Note: Skill 聚类校验与有限纠错

Status: implemented

[English](2026-11-02-skill-cluster-repair.en.md) | 中文

## Problem

真实模型可能重复分配或遗漏报告。单次非法分区直接终止 prepare，用户只看到笼统错误，无法区分违规原因。关联流程为 [m6-19](../../../flow/issues/m6-skill-codeagent-e2e.md)。

## Decision

HTTP 与 CodeAgent 使用同一组按阶段注册的提交工具。CodeAgent 通过受限 CLI 连接单个 stdio MCP 服务，每次只公布当前工具；HTTP 请求绑定同一工具的参数契约。调用只接受工具校验后的结果。传输、超时、取消及安全错误结束当前操作。

聚类在同一属性组内使用从 1 开始的报告短号，校验恰好覆盖一次后映射回冻结 ID 并生成簇 ID。核查校验快照引用和修复计划。编辑针对当前已接受的 Skill 快照，用唯一旧片段定位替换；后端整批检查冲突与文件安全后构造变更。反馈只允许引用验证集证据，归因引用必须包含当前版本。

整批聚类通过归属校验后，先保存冻结分组、来源映射和稳定的簇 ID，再开放问题聚类页。每簇开始、成功或失败时分别保存核查状态；失败保留脱敏原因和未核查的簇。prepare 重新进入时复用已完成的核查，全部成功后才按优先级生成候选轮次。这样后续核查失败也能检查已有聚类，并避免重排导致簇与修复计划错配。

## Alternatives considered

直接输出完整记录会要求模型复制标识与未改动文件内容。专用工具接收模型判断，由服务构造已有领域对象；自由执行脚本会扩大能力边界。

## Consequences

每个逻辑操作最多接受三次提交尝试，参数错误可按反馈重新提交，只有通过的一次交付给后续阶段。CLI 逐次记录提交结果，适配版本改变会触发已有恢复身份检查。
